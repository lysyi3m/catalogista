# Changelog

Features, changes and fixes in each App Store release, newest first.

## 1.1 — 2026-10-10

### Added

- The record page's cover opens the release's images in Quick Look; so do Show Images in the
  Actions menu and ⌘Y. A release with more than one image shows a count badge and a stack of
  sheets in the cover's colours.
- Move a copy to another folder from its page, from a cover's context menu, or by dragging it onto
  a folder in the sidebar.
- A Copy section on the record page: the copy's folder, date added and custom fields.
- macOS: the edition is a table beside the cover.
- macOS: clicking the sidebar folder a record was opened from goes back to that folder.

### Changed

- The tracklist opens expanded.

### Fixed

- A record opened before shows its cached details from the first frame.
- The Discogs credit stays on the bottom edge, and steady while a list scrolls.
- iOS: only the Discogs credit's link is tappable, not the space around it.
- Folder counts refresh after every sync, and covers reload once they are fetched.
- Removals, moves, additions and sign-out stay correct when they overlap a sync.
- A cancelled cover prefetch stops at once.
